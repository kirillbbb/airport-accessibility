# Воздушное окно

Исторический дашборд ограничений Шереметьево, Внуково, Домодедово и Жуковского. Разовый срез **23 сентября 2026, 00:00 — 23 октября 2026, 00:51 МСК**. Последний день неполный.

Готовый статический сайт: HTML/CSS/JavaScript, локальные JSON/CSV. Рабочего backend, базы, API-ключей и фонового сборщика на хостинге нет. Браузер читает файлы из `dist/data/`. Страницы `#calendar`, `#overview`, `#journal`, `#comparison`, `#sources` работают на одном `index.html`.

## Развернуть на Vercel

1. В Vercel выбрать Add New → Project и импортировать `kirillbbb/airport-accessibility`.
2. Root Directory — корень репозитория (`./`), Framework Preset — **Other**.
3. Output Directory — **dist**. Build Command и Install Command — пустые (Override). Эти значения уже заданы в `vercel.json`.
4. Переменные окружения не нужны. Нажать Deploy.

Сборка и установка зависимостей не требуются. [Официальная инструкция Vercel для статических проектов](https://vercel.com/docs/builds/configure-a-build#skip-build-step). Сам деплой пользователь выполняет в своём аккаунте; наличие конфигурации не означает, что удалённый деплой уже проверен.

## Открыть локально

Python 3.9+ и Node.js 20+ для проверок. Установка пакетов не требуется.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

Открыть `http://127.0.0.1:4173/#calendar`. Файлы ES-модулей и JSON нужно открывать через HTTP, а не двойным щелчком по HTML.

## Что есть в интерфейсе

- Общий календарь: все 31 дата, четыре аэропорта рядом, в каждой ячейке точная 24-часовая шкала с цветными участками режимов. В мобильной версии — горизонтальная прокрутка. Короткие участки доступны также по нажатию на дату.
- Обзор: эпизоды, аэропорто-часы, дни с записями, дневной график, сравнение аэропортов, распределение по часам и детализация дня.
- Журнал переходов, карточки эпизодов с первоисточниками и дополнительными сообщениями аэропортов.
- Фильтры дат, аэропортов, режима; CSV текущей выборки; полный JSON и CSV.
- Отдельные контекстные наблюдения с неизвестными границами и методология.
- «Сверка данных»: сравнение с msk-airports.ru, Airports.ru, BenzinMap и агрегаторами региональных оповещений; конкретные расхождения и оценка их влияния.

## Источники и воспроизведение

Архив `dist/data/evidence.zip` содержит только открытые исходные снимки и распознанные сообщения. Для воспроизведения распакуйте его командой ниже в `research/` (этот каталог не хранится в Git повторно). Манифест Росавиации содержит URL и SHA-256 всех 43 страниц. Дополнительные архивы и снимки агрегаторов также имеют контрольные суммы. Приватных данных или авторизации в проекте нет.

Повторная нормализация сохранённого среза, без сети:

```sh
python3 scripts/prepare_research.py
python3 scripts/normalize.py
python3 scripts/compare.py
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/model.test.mjs
node --check dist/app.mjs
```

Сборщики используют сохранённые страницы, когда они уже существуют:

```sh
python3 scripts/collect.py
python3 scripts/collect_airports.py
```

Даты фиксированы для этого исследования. Это не сервис текущих статусов. Новое исследование требует нового среза, границ, отдельных исходных снимков и повторной проверки источников.

## Как читать числа

98 эпизодов по аэропортам, 130 участков режимов. Один эпизод может сначала быть работой по согласованию, а затем ограничением приёма/выпуска. Одно общее объявление для четырёх аэропортов может дать четыре эпизода.

**353 ч 27 мин — сумма аэропорто-времени**, включая параллельные ограничения разных аэропортов. Это не длительность закрытия всего московского неба.

Границы основных рядов — время публикаций Росавиации. Они не являются установленным точным операционным временем. Работа по согласованию и объявленные ограничения приёма/выпуска считаются раздельно. Причина БПЛА не присваивается автоматически. Сигнал «ковёр» сохраняется в дополнительных исходных сообщениях, но не считается синонимом полного закрытия.

Непарные сводки 8518, 8771 и 8797 видны в интерфейсе и JSON, но не создают придуманных интервалов. Полнота фактических ограничений не гарантирована. Пустой участок означает отсутствие восстановленного интервала в текущих фильтрах. Данных для расчёта вероятности будущей задержки нет.

Подробности — [исследование](docs/RESEARCH.md), [проверки](docs/VERIFICATION.md), данные `dist/data/`.

Сверка: [подробный отчёт](docs/COMPARISON.md), [РСЧС и региональные агрегаторы](docs/RSCHS-AUDIT.md). 120/120 показанных переходов msk-airports.ru совпали. В CSV Airports.ru 113/130 наших участков совпали по обеим границам с допуском менее минуты; 13 нет в выгрузке, у 4 отличается окончание. У BenzinMap найдены ошибочные или необоснованные присвоения исходных сообщений аэропортам. Это проверка обработки открытых источников, не доказательство полноты реальной истории.
